Panel de servidores dinamicos — Windows PORTABLE
================================================

Copia la carpeta completa 'windows' a una carpeta escribible del usuario,
por ejemplo C:\Users\TU_USUARIO\Documents\Servers_Scripts\windows o D:\Proyectos.
No la coloques en C:\, C:\Program Files ni C:\Windows: son rutas protegidas.
El disco C: SI funciona si tu carpeta permite escritura.
Ejecuta:

  iniciar.cmd

Requiere Windows x64 y PowerShell 5.1. No requiere instalar Python
ni librerias a mano. En equipos de 32 bits no funciona este paquete.

Que incluye
- runtime\python\     Python 3.12 embeddable (portable)
- runtime\get-pip.py  instalador de pip
- vendor\wheels\      fastapi, uvicorn, httpx, etc. (offline)
- iniciar.ps1         comprueba archivos/permisos y Python portable,
                      instala librerias localmente e inicia todo

El error tipico de WindowsApps\python.exe queda resuelto:
ese acceso directo NO es Python; el script usa siempre runtime\python.

Primera ejecucion
- Instala pip + librerias en runtime\python (unos segundos)
- Siguientes veces reutiliza lo instalado
- Si faltan wheels, intenta PyPI (necesita internet).
- Para verificar sin arrancar servidores:
  powershell -NoProfile -ExecutionPolicy Bypass -File .\iniciar.ps1 -CheckOnly

URLs (puertos 2800x para evitar reservas de Hyper-V/WSL en ~8000)
- Panel: http://127.0.0.1:5500/ (o el que indique la consola)
- API:   http://127.0.0.1:28000/
- Docs:  http://127.0.0.1:28000/docs

La barra indica etapas reales; el spinner braille anima las esperas si
la terminal admite UTF-8. En otras terminales usa ASCII.
Si un puerto de API esta ocupado, cierralo tu; el script no detiene
otros programas. La UI busca otro puerto. Si falla, mira logs\.
Ctrl+C detiene los procesos que este lanzador inicio.
